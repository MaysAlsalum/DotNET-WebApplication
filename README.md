# 🌐 DotNET-WebApplication

A web application developed using **ASP.NET Core MVC** to demonstrate modern web development concepts, including the MVC architecture, responsive user interfaces, and database integration.

This project was developed for learning and educational purposes to practice building scalable web applications using Microsoft's .NET platform.

---

## ✨ Features

- 🖥️ ASP.NET Core MVC Architecture
- 📄 Dynamic Web Pages
- 📦 CRUD Operations
- 💾 Database Integration
- 🧭 Routing & Navigation
- ✅ Model Validation
- 🎨 Responsive User Interface
- 🔒 Error Handling

## Getting Started

### Clone the repository

```bash
git clone https://github.com/MaysAlsalum/DotNET-WebApplication.git
```

### Navigate to the project

```bash
cd DotNET-WebApplication
```

### Configure the database

Update the connection string in:

```
appsettings.json
```

### Run the application

```bash
dotnet run
```

Or simply open the solution in **Visual Studio** and press **F5**.
